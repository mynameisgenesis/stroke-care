# Rebound icons

Ten individual RGBA PNG icons, each exported at 128 × 128 and 256 × 256 pixels. Names use `<feature>-<size>.png`:

- home
- exercises
- progress
- history
- start-therapy
- settings
- timer
- completed
- add-exercise
- accessibility

Palette: teal #008F8B, navy #142B43, aqua #A8DDDE. Each export uses a shared 32-unit canvas with a centered 24-unit Material glyph and transparent padding. Backgrounds and glyph cutouts preserve transparency; anti-aliased edges retain partial alpha.

Artwork is rendered from the project's installed @mui/icons-material TwoTone icons (Home, GridView, BarChart, History, PlayCircle, Settings, Timer, CheckCircle, AddCircle, AccessibilityNew). Secondary shapes use solid aqua; main shapes use teal, with navy for History and Settings. See LICENSE.txt.

The earlier conversation exposed the palette and requested icon meanings, but its reference image was unavailable. These exports follow that written direction and the existing Material icon family rather than an exact pixel match to the sheet. No image generation model was used.

The PNGs are assets only; no screens, navigation, or app behavior are connected or changed.
